# 🚀 Быстрый старт — AI × SEO презентация

## ✅ Проект успешно создан!

Все файлы находятся в папке `ai-seo-presentation` на вашем рабочем столе.

## 📦 Что дальше?

### Шаг 1: Установите Node.js

Сейчас на вашем компьютере не установлен Node.js. Это необходимый инструмент для запуска проекта.

**Как установить:**

1. Откройте браузер и перейдите на https://nodejs.org/ru/
2. Нажмите на зелёную кнопку **"Загрузить LTS"** (рекомендуемая версия)
3. Запустите скачанный файл установщик
4. Следуйте инструкциям установщика (можно оставить все настройки по умолчанию)
5. После установки **перезапустите PowerShell**

### Шаг 2: Проверьте установку

Откройте новое окно PowerShell и выполните команды:

```powershell
node --version
npm --version
```

Если видите номера версий (например, `v20.10.0` и `10.2.3`) — всё установлено правильно! ✅

### Шаг 3: Установите зависимости проекта

Перейдите в папку проекта и установите необходимые библиотеки:

```powershell
cd ai-seo-presentation
npm install
```

Установка займёт несколько минут. Дождитесь завершения.

### Шаг 4: Запустите презентацию

После установки зависимостей запустите проект:

```powershell
npm run dev
```

Вы увидите сообщение:
```
- Local:   http://localhost:3000
```

Откройте браузер и перейдите по адресу **http://localhost:3000** 🎉

## 🎮 Управление презентацией

После запуска вы увидите интерактивную презентацию. Управление:

### Клавиатура
- **→** или **Пробел** — следующий слайд
- **←** — предыдущий слайд
- **Home** — первый слайд
- **End** — последний слайд
- **Page Down / Page Up** — перелистывание

### Мышь
- Кнопка **"Далее"** внизу справа
- Кнопка **"←"** для возврата
- Кликните на точки навигации для перехода к конкретному слайду

### Сенсорный экран
- Свайп влево — следующий слайд
- Свайп вправо — предыдущий слайд

## 🔧 Частые вопросы

**Q: Презентация не открывается в браузере**  
A: Убедитесь, что сервер запущен (`npm run dev`), и перейдите на http://localhost:3000

**Q: Ошибка при выполнении `npm install`**  
A: Проверьте подключение к интернету и попробуйте снова

**Q: Анимации работают медленно**  
A: Закройте лишние вкладки браузера или используйте режим производительности

**Q: Хочу изменить содержание слайдов**  
A: Откройте файл `app/page.tsx` в любом текстовом редакторе
