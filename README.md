# AI × SEO — Интерактивная презентация

Современная интерактивная презентация о применении нейросетей в SEO-оптимизации сайтов.

## 📋 Требования

Для запуска проекта вам потребуется:
- **Node.js** версии 18 или выше
- **npm** (устанавливается вместе с Node.js)

## 🚀 Установка

### 1. Установка Node.js

Если у вас ещё не установлен Node.js, скачайте и установите его с официального сайта:

**Для Windows:**
- Перейдите на https://nodejs.org/
- Скачайте LTS версию (рекомендуется)
- Запустите установщик и следуйте инструкциям

После установки проверьте версии в PowerShell:
```powershell
node --version
npm --version
```

### 2. Установка зависимостей

Откройте PowerShell в папке проекта `ai-seo-presentation` и выполните:

```powershell
npm install
```

Эта команда установит все необходимые пакеты:
- Next.js — фреймворк для React
- React — библиотека для UI
- Motion — анимации
- Lucide React — иконки

## 💻 Запуск проекта

### Режим разработки

Для запуска в режиме разработки с горячей перезагрузкой:

```powershell
npm run dev
```

Затем откройте браузер и перейдите по адресу: **http://localhost:3000**

### Сборка для production

Для создания оптимизированной сборки:

```powershell
npm run build
npm run start
```

## 🎯 Особенности презентации

### Навигация
- **Клавиатура:** стрелки влево/вправо, Page Up/Down, пробел, Home, End
- **Мышь:** кнопки "Назад"/"Далее", точки навигации внизу
- **Сенсорные экраны:** свайп влево/вправо

### Содержание (10 слайдов)
1. **Введение** — Обзор применения ИИ в SEO
2. **Основы SEO** — Видимость, соответствие, удобство
3. **Возможности ИИ** — Автоматизация и ускорение работы
4. **Поисковые намерения** — Группировка запросов
5. **SEO-тексты** — Редакционный процесс
6. **Метатеги** — Title и Description
7. **Аналитика** — Поведенческие данные
8. **UX и техника** — Интерфейс и производительность
9. **Практика** — Пошаговый сценарий
10. **Выводы** — Ответственное применение ИИ

### Доступность
- Полная поддержка клавиатурной навигации
- ARIA-атрибуты для скринридеров
- Режим уменьшенной анимации (prefers-reduced-motion)
- Семантическая HTML-разметка

### Адаптивность
Презентация адаптирована для всех размеров экранов:
- Десктоп (1600px+)
- Планшет (950px–1600px)
- Мобильные устройства (до 680px)

## 🔧 Устранение неполадок

### Проблема: `npm` не распознаётся
**Решение:** Установите Node.js с https://nodejs.org/

### Проблема: Порт 3000 занят
**Решение:** Next.js автоматически предложит другой порт, или остановите процесс на порту 3000

### Проблема: Ошибки при установке зависимостей
**Решение:** 
```powershell
Remove-Item node_modules -Recurse -Force
Remove-Item package-lock.json
npm install
```
